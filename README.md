# Portfolio

🌐 **Live site:** https://mdbellalhosen.github.io/Portfolio/

A personal portfolio repository showcasing my projects, skills, and development work in one organized place.

**Live files:** `index.html`, `styles.css`, `script.js`, `assets/`

## Highlights
- Fully responsive layout (phone, tablet, desktop) with an animated mobile menu
- Interactive 3D hero built with Three.js (pauses when off-screen, falls back gracefully)
- 3D tilt cards, 3D scroll-reveal, animated skill rings and counters
- Five working themes (Default, Light, Cyberpunk, Glass, Neon) saved per visitor
- Project filter + details modal, testimonial carousel (swipe on mobile), code showcase with syntax colours
- Contact form with validation that opens the visitor's email app
- Accessible: keyboard-friendly dialogs, skip link, reduced-motion support

## Deploy on GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / root → Save.
